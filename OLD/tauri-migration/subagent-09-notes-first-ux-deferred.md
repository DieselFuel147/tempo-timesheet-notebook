# Sub-Agent 09 - Notes-First UX Deferred

## Status

Deferred. Do not execute during the migration-to-parity phase.

## Mission

After the Tauri migration is stable, redesign the product toward notes-first capture with inferred time entries.

## Scope

Future scope may include:

- notes-first primary interface
- inference or suggestion of time segments from notes
- summary suggestion integrated into the capture flow
- keyboard-first capture improvements
- preservation of push-readiness and validation clarity

## Pre-Conditions

Do not start until all of these are true:

- Tauri-native app is the main runtime path
- internal Fastify server is no longer required
- current parity flows are working
- packaging/distribution path is credible
- settings and credentials are no longer primarily `.env`-based

## Deliverable Expectations Later

When this brief is activated later, it should start with research and UX structure, not immediate broad UI churn.
